# mathpoint.io

An SAT Math platform that diagnoses student weaknesses at an unprecedented level of detail.

## How It Works

1. **Adaptive Diagnostic** — Student takes a 15-20 minute assessment that adapts to their skill level
2. **Micro-Skill Analysis** — System identifies exactly which skills they're missing, across 19 topics and 2,000+ questions tagged by pattern, variant, and difficulty
3. **Clear Results** — Student sees a skill checklist (✅/❌) showing strengths and weaknesses
4. **Smart Practice** — System prescribes a practice sequence ordered by skill dependencies and SAT point recovery potential
5. **Targeted Improvement** — Student practices with adaptive questions targeting their specific gaps

## The Insight

SAT difficulty isn't about harder math — it's about cognitive approach. Hard questions reward pattern recognition over computation. MathPoint teaches students to see what the SAT is actually testing.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Database**: PostgreSQL + Prisma ORM
- **Styling**: Tailwind CSS v4
- **UI**: Radix UI + shadcn/ui
- **Math**: KaTeX for LaTeX rendering
- **State**: Zustand
- **Animations**: Framer Motion
